බිම්මල් අයියා — Android සඳහා install කළ හැකි වෙබ් ඇප් එක

ඔයාගේ කලින් බිම්මල් පැකට් ඡායාරූපයේ තිබූ මුල් ලෝගෝව කපාගෙන ඇප් එකේ header එකට සහ icon එකට යොදා ඇත. ඡායාරූපයේ ලෝගෝව කුඩා බැවින් icon එකේ පැහැදිලි බව සීමිත විය හැක.

පහසුකම්:
- පොට් ගණන හා ඉතිහාසය
- දිනපතා අස්වැන්න (kg)
- විකුණුම්, ලැබුණු මුදල් සහ හිඟ මුදල්
- වියදම් සහ සරල ලාභ ගණනය
- JSON backup/restore සහ CSV වාර්තාව
- Home-screen icon, PWA manifest සහ offline cache

Android ෆෝන් එකේ සාමාන්‍ය ඇප් එකක් වගේ install කිරීමට:
1. මෙම ෆෝල්ඩරයේ සියලුම ගොනු HTTPS සහිත වෙබ් සත්කාරකයකට upload කළ යුතුය.
2. Chrome එකෙන් එම HTTPS ලිපිනය විවෘත කරන්න.
3. 'Install app' බොත්තම හෝ Chrome මෙනුවේ 'Install app' / 'Add to Home screen' තෝරන්න.

සටහන්:
- මෙය PWA (home-screen installable web app) පැකේජයකි; Android APK ගොනුවක් හෝ Play Store app එකක් නොවේ.
- HTTPS hosting එකක් නොමැතිව සාමාන්‍ය install පහසුකම් සක්‍රිය නොවේ.
- දත්ත browser local storage තුළ තබාගනී. Browser data මකා දැමීමෙන් දත්ත නැතිවිය හැකි නිසා Backup ගොනුවක් නිතර බාගන්න.
